# Pplataformas_n
# PUJ Cali

> Aplicación web progresiva (PWA) enfocada en el carpooling universitario para estudiantes de la Pontificia Universidad Javeriana Cali.

## Descripción

Pplataformas es una Progressive Web App (PWA) diseñada para simular una plataforma moderna de carpooling universitario para estudiantes de la Pontificia Universidad Javeriana Cali.

La aplicación presenta una interfaz inspirada en dispositivos iPhone, con un diseño moderno, minimalista y responsive, orientado a brindar una experiencia visual atractiva e intuitiva.

El proyecto busca representar una solución tecnológica enfocada en:

* Compartir cupos de transporte entre estudiantes.
* Reducir gastos de movilidad.
* Disminuir la congestión vehicular.
* Incentivar la movilidad colaborativa y sostenible dentro de la universidad.

---

# Características principales

* Interfaz estilo aplicación móvil iPhone.
* Pantalla splash animada de inicio.
* Diseño moderno y minimalista.
* Modo claro y oscuro persistente mediante LocalStorage.
* Compatibilidad con Progressive Web App (PWA).
* Implementación de Service Workers.
* Instalación desde navegador como aplicación.
* Responsive design adaptable a móviles y escritorio.
* Uso de animaciones y transiciones modernas.
* Optimización de experiencia visual y de usuario.

# Instalación y ejecución

## 1. Clonar el repositorio

```bash
git clone https://github.com/NicolasCuastumalCordoba/Pplataformas_n.git
```

## 2. Abrir el proyecto

Abrir la carpeta del proyecto en Visual Studio Code o cualquier editor compatible.

## 3. Ejecutar

Abrir el archivo `index.html` en el navegador o utilizar una extensión como Live Server.
